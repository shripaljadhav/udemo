# Pehla Page — Brand (Kids Activity Books)

## Voice
Warm, simple, encouraging. One short instruction per page. Ages ~3–6.

## Visual system
- Background: clean white for print/coloring
- Titles: dark navy (`#1B3A6B`), rounded sans (Nunito)
- Accents: festive orange `#F28C28`, marigold yellow `#F5C518`, pink `#F07AB0`, leaf green `#4CAF50`
- Line art: thick black outlines (`#1A1A1A`, ~3–5px) for easy coloring
- Motifs: marigolds, sparkles, confetti dots, diyas, kandils, rangoli

## Page chrome
- Series title top-left
- Logo top-right
- Activity title + one-line instruction
- Orange/yellow rule under header
- Page number in navy circle at footer with sparkle accents

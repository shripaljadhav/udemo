# My First Diwali Art Adventure

Print-ready Pehla Page kids activity book (ages 3–6).

## Deliverable

- **PDF:** [`docs/pdf/My-First-Diwali-Art-Adventure.pdf`](../../docs/pdf/My-First-Diwali-Art-Adventure.pdf) (A4, 14 pages)

## Contents

| Page | Activity |
|------|----------|
| Cover | Title + cute diya |
| 1 | Join the Diya Dots |
| 2 | Copy the Kandil (4×4 grid) |
| 3 | Dot-Color the Rangoli |
| 4 | Finish the Gift Box (symmetry) |
| 5 | My Festive Diwali Home |
| 6 | Learn to Draw a Cute Diya |
| 7 | Festival Fun at Home |
| 8 | Trace the Hanging Lanterns |
| 9 | Lotus Diya Color by Number |
| 10 | Color the Sweet Plate as Shown |
| 11 | Count the Glowing Diyas |
| 12 | Maze to the Diwali Party |
| 13 | Certificate |

## Rebuild

```bash
cd books/my-first-diwali-art-adventure
python3 scripts/build_book.py
```

Requires Google Chrome (headless) for PDF output. Source of truth is `scripts/build_book.py` + `assets/book.css`.
